# 为什么学 Markdown 像做菜？

你好！这是我的**第二篇文章**。这也是一篇专门用来练习 Markdown 语法的文章。
如果不学会这些语法，写出来的博客就像“没放盐的番茄炒蛋”，虽然能吃，但没有灵魂。

## 一、 食材准备（列表语法）

写博客和做菜一样，得先准备食材

### 1.1 必需品（无序列表）
- 键盘（建议机械键盘）
- 想法（这个很重要）
- Hexo（我们的锅）

### 1.2 步骤（有序列表）
1. 想好些什么
2. 打开 Markdown 编辑器
3. 开始敲字

---

## 二、 火候控制（强调与引用）

有时候你需要加重语气，就像大火爆炒；有时候需要轻声细语，就像小火慢炖。

- **这是大火爆炒（加粗）**：重点内容！
- *这是小火慢炖（斜体）*：稍微注意一下。

> 做菜要讲究“色香味俱全”，写文章要讲究“排版清晰”。—— Xiaobei（引用）

## 四、 核心食谱（代码块）

最后，我们把做菜的过程封装成一个 Python 函数。
**注意观察：** 这一段背景是黑色的，而且有行号，这就是代码块。

{% codeblock lang:python %}
class TomatoEgg:
    def __init__(self, egg_count, tomato_count):
        self.eggs = egg_count
        self.tomatoes = tomato_count
    
    def cook(self):
        print("1. 打散鸡蛋")
        print("2. 切好番茄")
        print("3. 起锅烧油！")
        return "Delicious!"

# 开始做菜
dinner = TomatoEgg(4, 2)
dinner.cook()
{% endcodeblock %}
