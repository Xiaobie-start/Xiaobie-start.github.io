🍳 为什么学 Markdown 像做菜？

你好！这是我的第二篇文章。这也是一篇专门用来练习 Markdown 语法的文章。
如果不学会这些语法，写出来的博客就像“没放盐的番茄炒蛋”，虽然能吃，但没有灵魂。

一、 食材准备 (列表语法)

写博客和做菜一样，得先准备素材：

1.1 必需品 (无序列表)

  • 键盘 (建议机械键盘)
  • 想法 (这个最重要)
  • Hexo (我们的锅)

1.2 步骤 (有序列表)

  1. 想好要写什么
  2. 打开 Markdown 编辑器
  3. 开始敲字

二、 火候控制 (强调与引用)

有时候你需要加重语气，就像大火爆炒；有时候需要轻声细语，就像小火慢炖。

  • 这是大火爆炒（加粗）：重点内容！
  • 这是小火慢炖（斜体）：稍微注意一下。

引用：做菜要讲究“色香味俱全”，写文章要讲究“排版清晰”。—— 鲁迅 (没说过)

三、 算算卡路里 (数学公式)

既然是技术博客，总得算算账。假设番茄的热量是 $\alpha$，鸡蛋的热量是 $\beta$。

那么这道菜的总热量 $E$ 是：

$$ E = \sum_{i=1}^{n} (\alpha_i + \beta_i) + \text{Oil} $$

(看到上面那个酷炫的公式了吗？这就是 Markdown 的魔力！)
