视觉感知基础：什么是卷积核

发表于 2025-12-14 分类于 CV 学习笔记

👁️ 视觉矩阵的滤镜

在计算机视觉的地下世界中，图像是一堆像素矩阵，而卷积核（Kernel）就是作用于这个矩阵上的定制滤镜。它负责提取图像中的关键特征，就像黑客入侵时过滤数据流一样。

卷积核的作用机制

简单来说，卷积核就是一小块矩阵（比如 $3 \times 3$ 或 $5 \times 5$），它在整个图像矩阵上滑动，并执行元素乘积和求和操作。

⚙️ 核心代码：边缘检测

最经典的卷积核就是用于边缘检测的内核。这个内核能突出图像中像素变化剧烈的地方，就像在黑暗城市中锁定霓虹灯的轮廓。

```python
import numpy as np

这是一个经典的 3x3 边缘检测卷积核（Sobel 或 Prewitt 算子简化版）

edge_kernel = np.array([
[-1, -1, -1],
[-1, 8, -1],
[-1, -1, -1]
